# riccardo-bedogni-portfolio

Personal portfolio — Astro 5 + Vue islands, hand-written CSS, bilingual (EN `/`, IT `/it/`).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build && npm run preview
```

- Design tokens: `src/styles/tokens.css` · style tile at `/styleguide` (not indexed)
- UI strings: `src/i18n/{en,it}.json`
- Open content items: `CONTENT_TODO.md`
